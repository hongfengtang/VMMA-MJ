## 范围与约定

这里记录的是当前源码行为，不是中控服务端实现或设备厂商完整协议。源码保留但界面未接线的功能会单独注明；医院现场的账号权限、网络、设备参数和作业审批由部署方提供。

界面按钮名称保留源码中的繁体中文，解释使用简体中文。示例只使用占位值，不记录真实密码、令牌、内部地址或患者资料。

修改入口、配置、接口、设备流程或按钮后，应同步维护对应文档；历史变更保留在 [CHANGELOG.md](../CHANGELOG.md)，不能代替当前设计说明。
